# 展示内容与后台管理使用手册

这份文档对应当前代码里的展示位、展示组、分享 Profile、专题案例和桌面读取实现。展示内容只能由管理员在后台维护，普通用户不能通过权限 Key 自行提交内容。

## 先认清三个概念

- **展示位**：页面上的展示位置，例如生成区头部、页面顶部、历史面板上方。
- **展示组**：某个展示位上的一套展示配置，包含名称、备注、启停、时间窗、轮播间隔和切换方式。
- **展示约束**：展示组上的可选生效条件。现有开始/结束时间是基础时间约束；后台还可以为展示组增加指定域名约束。
- **展示素材**：展示组里的单张图片。多张素材放在同一个展示组里，前端会按排序轮播。
- **引导位**：站点级公开 UI 配置，例如缺 API Key 时展示的购买入口。它不属于单个用户的本地设置。
- **专题案例**：围绕老照片修复、虚拟试衣、创意风格化等用户任务组织的案例和安全配方。专题负责内容与复现流程，Promo 只负责把入口投放到指定展示位。

展示优先级是：

1. 分享展示组：分享链接带 `promoProfileId`，且后台存在有效分享展示组。
2. 全局展示组：普通访问或分享展示组失效时使用。
3. 旧环境变量展示内容：仅作为 `generation_form_header` 的兼容兜底。

## 管理员怎么配置

管理员入口是 `/admin`，展示内容入口是 `/admin/promo`。

专题案例入口是 `/admin/showcases`。公开用户可以在工作台下方或 `/topics` 浏览专题；点击案例后只会把图片、提示词和允许参数载入工作台，不会自动生成或修改 API Key、Base URL。工作台已有源图时，用户可以在引导 Dialog 中选择替换或追加；当前模型不兼容时可直接打开模型设置，调整后再继续载入。

API Key 购买或使用引导入口在 `/admin/public-actions`。它用于维护缺配置提示中追加的纯文字按钮，不用于保存或代填用户 API Key。

## 专题案例管理

`/admin/showcases` 沿用现有 owner/admin/viewer 权限：

- `owner`、`admin` 可以新建、保存、预览、发布、下线、归档和回滚。
- `viewer` 可以查看草稿、前台预览和发布记录，但写操作禁用。
- 创建、更新、发布、下线、归档和回滚都会写入审计日志。

当前后台默认使用结构化编辑器，并保留“高级 JSON”作为完整能力与故障排查入口。结构化编辑器支持：

- 专题基础字段、推荐状态、排序、标签和双语任务分类；
- 中英文标题、摘要、准备说明、限制、能力说明、适用性和推荐输入质量；
- 专题 FAQ 与相关专题；
- 案例中英文标题、默认 prompt、用户补充要求及可选 `user_instruction` 占位符；
- 输入槽位中英文名称与说明、必填状态、最少/最多图片数、允许 MIME、角色与顺序；
- 任务模式、prompt 应用方式、模型能力要求和推荐模型；
- 固定尺寸、场景尺寸、自定义尺寸（单个“宽×高”输入）、质量、数量、格式、压缩、背景和审核参数；
- 服务端专题媒体上传、媒体库选择、专题/案例封面及输入/输出示例指派；
- 复制当前专题为新的草稿。

完整目录对象包含：

- `topic`：专题标题、摘要、准备说明、限制、标签、推荐状态、排序、封面和案例顺序。
- `cases`：案例标题、输入/输出媒体、输入槽位、默认 prompt、能力要求和输出参数。
- `assets`：内置占位媒体、经过安全校验的公开 HTTPS 图片或服务端托管媒体。
- `startsAt` / `endsAt`：可选的公开时间窗。

保存草稿不会影响线上版本。点击“预览草稿”会复用公开专题组件显示当前内容；点击“发布新版本”才会生成不可变快照并切换公开指针。下线只从公开目录移除，草稿和发布历史仍保留；回滚会把选中的历史快照复制为一个新发布版本，不会改写旧快照。

安全限制：

- JSON 必须同时提供简体中文和英文内容，并通过同一 `ShowcaseCatalog` / `ShowcaseRecipeV1` schema。
- 不允许 API Key、Token、密码、脚本、HTML 事件、本地路径、私网 URL、base64 图片或自动提交字段。
- 媒体 URL 只允许安全的公开 HTTPS 地址；内置默认案例目前使用明确标识的 CSS 演示占位素材。
- 服务端上传仅支持 JPEG、PNG、WebP、AVIF，单文件不超过 12 MB；系统会真实解码、限制边长和像素数、自动修正方向、清除 EXIF，并生成 WebP 展示图和缩略图。
- 上传时必须填写中英文替代文本、版权来源和授权说明。仍被草稿或任一发布版本引用的托管媒体不能永久删除。
- 发布前会复查托管媒体的文件存在性、大小、checksum、尺寸和可解码性；损坏媒体不会切换线上版本。
- 外部 HTTPS 媒体发布时会逐跳解析 DNS、拒绝私网/保留地址并把 HTTPS 连接固定到已校验 IP；每次重定向都会重新复检。探测限制默认端口、敏感查询参数、3 次重定向、10 秒总预算和 12 MB 响应体，并校验响应 MIME、Sharp 实际格式、像素和声明尺寸；失败不会创建发布版本。
- 专题发布后，Web 公开端读取 `/api/showcases`；桌面端复用桌面内容服务来源并映射到 `/api/showcases`，请求失败时回退到缓存和内置目录。
- 支持扩展字段的客户端会通过 `x-showcase-client-version: 2` 声明扩展 wire 契约（不是 catalog schema v2），并获得未来 recipe 的单案例只读降级；旧客户端继续读取严格 v1 目录，无法理解的未来案例会被过滤，而不会拖垮其他专题。

结构化编辑器已覆盖日常运营字段；高级 JSON 主要用于完整导入导出、批量调整和诊断。自定义尺寸使用单个“宽×高”输入，输入过程中不会因只完成宽或高的一侧而被清空；保存时才拆分为 `customWidth` / `customHeight`。后台会在尺寸字段切换时清理互斥的 `scenarioId` / `customWidth` / `customHeight`，清空尺寸、质量、格式、背景或审核也会真正移除旧值。用户补充要求的占位符开关会同步写入或清理双语 prompt；选择具体 MIME 会自动取消 `image/*` 通配，重新选择通配则清空具体类型。案例填写的推荐模型 ID 会在满足能力条件的模型中优先排序，但不会强制切换供应商或覆盖用户配置。

后台顶部提供近 30 天匿名专题漏斗汇总，包括专题曝光、专题打开、配方应用和生成成功，并允许 owner/admin 导出同一时间窗内的受控 NDJSON 事件用于离线汇总。前端事件会写入有界本地队列，首次发送失败按 1 秒档开始有限退避重试，调度器等待最早到期事件；页面隐藏或关闭时优先尝试 Beacon；Beacon 不可用或失败时继续走 `fetch keepalive` 或保留队列；同一目录版本内同一专题的曝光按会话去重。事件不包含图片、图片 hash、本地路径、完整 prompt、个性化要求、API Key、Base URL、IP 或跨站用户标识；发送失败不会阻断创作。

公开专题中心支持关键词、输入类型、能力标签和任务分类筛选，并提供推荐优先、最近更新和新手友好排序。专题卡会显示图片数量要求和当前模型/凭据可用状态；状态会在配置、表单偏好或页面恢复后重新计算，并以当前表单选中的供应商实例为准。只读未来 recipe 显示“输入要求未知”，不会被误显示为“无需图片”或进入图片数量筛选。案例卡展示输入槽位角色和顺序，详情页可复制默认提示词；紧凑案例卡也能在触摸设备上切换前后对比模式。

正式案例仍需要准备经授权、经过实际流程生成和人工审核的输入/输出图片；内置 24 个案例媒体仍是明确标识的 CSS 演示占位，不应当作真实 AI 输入输出案例。服务端托管媒体目前使用本机持久目录（`SHOWCASE_MEDIA_DIR`，未配置时与后台 SQLite 同级），多实例部署应使用共享持久卷；S3 兼容后台媒体存储尚未实现。

### 1. 展示位

在展示位区域确认展示位置是否存在。当前默认展示位有：

- `generation_form_header`
- `app_top_banner`
- `history_top_banner`

展示位控制位置本身是否可用，以及默认轮播间隔和默认切换方式。

### 1.1 展示组比例

展示比例现在由 **展示组** 决定。新建全局展示组或分享展示组时，管理员可以选择常见比例，也可以输入自定义比例。前端会按展示组比例保留展示区域，PC 和移动端使用同一个比例；同一个展示组里的所有素材也必须共用这个比例。

前端使用完整展示方式：图片会在展示组比例容器内完整显示，不会为了铺满容器而裁切。素材图片本身比例与展示组比例一致时效果最好；如果不一致，图片仍会完整显示，但可能出现上下或左右留白。多张素材轮播时，暂停/播放按钮显示在展示图右侧，不会遮挡图片内容。

后台内置的常见比例包括：

- 方形：`1:1`
- 竖版卡片：`4:5`、`3:4`、`2:3`、`9:16`
- 横版卡片：`5:4`、`4:3`、`3:2`、`16:9`
- 分享卡片：`1.91:1`、`2:1`
- 横幅：`3:1`、`4:1`、`5:1`、`10:1`
- 超宽：`21:9`、`12:1`

各展示位的新建默认值是：

| 展示位                   | 默认比例 | 说明                                                                                                          |
| ------------------------ | -------- | ------------------------------------------------------------------------------------------------------------- |
| `generation_form_header` | `4:1`    | 输入/编辑卡片标题右侧小横幅，空间较小。若选择方形或竖版比例，前端会按比例展示，但需要确认不会挤压主表单区域。 |
| `app_top_banner`         | `10:1`   | 页面标题下方全宽横幅，适合横向信息；也可以按活动物料改为 `16:9`、`4:5`、`1:1` 等比例。                        |
| `history_top_banner`     | `10:1`   | 历史面板上方横幅，尺寸策略与页面顶部一致。                                                                    |

选图注意：

- 先根据已有物料选择展示组比例，再上传素材，不需要为了固定展示位比例重做物料。
- 同一展示组内的桌面图和移动图建议使用同一比例，只针对文字大小、信息密度和细节做不同版本。
- 生成区头部空间较小；如果沿用默认 `4:1`，素材内容应保持简洁，避免小字号长句。
- 关键内容放在画面中间，不要贴边；即使完整显示，边缘内容也容易被圆角或浏览器缩放影响。
- 建议导出 WebP/AVIF，单张控制在 `150 KB` 以内；如果是透明 PNG，要确认浅色和深色主题都能看清。
- 如果素材必须包含二维码，优先放在画面中部偏左或中部，并确认在移动端尺寸下仍清晰可扫。

### 2. 全局展示组

在全局展示组 Tab 中创建。

全局展示组需要填写：

- 名称：后台识别用。
- 备注：展示目的、来源或审核说明。
- 展示位：选择展示位置。
- 展示比例：选择常见比例或自定义比例，同一个展示组内所有素材都会按这个比例展示。
- 展示约束：默认所有域名均显示；也可以选择仅指定域名显示。
- 启用状态。
- 开始/结束时间：留空表示立即开始或长期有效。
- 间隔和切换：留空间隔时继承展示位默认值。

### 3. 分享展示组

在分享展示组 Tab 中创建。

分享展示组同样有名称、备注、展示位、展示比例、展示约束、启停、时间窗、间隔和切换方式。不同点是：保存后系统会自动生成 `Profile ID`，管理员只需要复制这个 ID 给用户。

管理员不需要、也不能手动填写 `Profile ID`。这样可以避免外部用户绕过审核自行提交展示内容。

用户拿到 `Profile ID` 后，可以在分享面板的 Profile ID 输入项中填写，生成的分享链接会携带：

```text
?promoProfileId=系统生成的ID
```

### 3.1 指定域名展示

展示组默认在所有访问域名下都可生效。如果同一套应用绑定了多个域名，可以把全局展示组或分享展示组限制为仅在指定域名下展示。

后台支持填写：

- 精确域名：`site-a.example.com`
- 带端口域名：`localhost:3000`
- 完整 URL：`https://site-a.example.com/path`，保存时只保留 host
- 通配子域名：`*.example.com`

编辑展示组时可以点击“添加当前域名”快速写入当前后台访问域名，也可以在归一化后的规则 chip 上删除单条规则。展示组列表支持按名称、展示位、Profile ID、域名和约束摘要搜索，素材管理页顶部会显示当前展示组约束，避免维护素材时忘记站点限制。

公共读取接口会根据实际请求 `/api/promo/placements` 的域名筛选展示组。分享展示组的域名不匹配时，即使链接带了正确的 `promoProfileId`，也会降级到当前域名匹配的全局展示组；没有全局展示内容时隐藏展示位。

如果同一展示位同时有“所有域名”展示组和当前域名专属展示组，当前域名专属展示组优先生效。这样可以保留一个全域兜底组，同时给测试站、品牌站或客户站配置专属内容。

### 4. 管理展示素材

不要在展示组列表页直接编辑素材。现在每个展示组都有独立素材页：

1. 进入全局展示组或分享展示组 Tab。
2. 找到目标展示组。
3. 点击 **管理素材**。
4. 在子页面里新增、编辑、停用或删除该展示组的素材。

同一个展示组下可以放多张素材：

- `桌面图 URL` 和 `移动图 URL` 至少填写一个；只填一个时，另一端会沿用同一张图。
- `标题`、`替代文本` 和 `点击链接` 都是可选项；不填点击链接时，前端只展示图片，不提供跳转。
- `排序` 小的先显示。
- `排序` 相同时，`权重` 大的优先。
- `设备` 为 `all` 时桌面和移动都展示。
- 所有素材都使用展示组比例预览和展示；不要在同一个展示组里混放不同比例的物料。

## 分享 Profile 的使用逻辑

分享 Profile 不是权限 Key。它只是一个公开读取 ID。

- 管理员创建分享展示组。
- 系统自动创建 `Profile ID`。
- 管理员审核并配置素材。
- 管理员复制 `Profile ID` 给用户。
- 用户只把这个 ID 放进分享链接。

如果分享展示组被停用、过期、素材全部失效或展示位被停用，前端会降级到全局展示组；没有全局展示内容时则隐藏展示位。

## 短链与推荐内容

管理员入口是 `/admin/short-links`。

短链管理用于把较长的分享链接保存为 `/s/{code}` 形式，同时查看访问情况。短链不会由前端自动创建，用户必须在分享面板里点击 **创建短链**。

后台可以配置：

- 是否开启短链功能。
- 创建模式：关闭创建、仅管理员、管理员 + 创建口令、公开创建。
- 创建口令、短码长度、默认有效期、目标 URL 最大长度。
- 是否允许明文敏感参数进入短链目标；`#key=` 解密密码允许进入短链目标，但会作为风险标记记录。
- 允许创建短链的站点域名。当前请求域名会自动允许；多个域名指向同一服务时，短链返回的域名跟随实际访问域名。

每条短链都可以设置推荐内容策略：

- **继承长链接**：保留原分享链接中的 `promoProfileId`。
- **不展示分享推荐**：跳转时移除 `promoProfileId`。
- **绑定指定 Profile**：跳转时覆盖为后台选定的分享 Profile。

因此，同一个分享内容可以通过不同短链关联不同推荐内容；管理员后续调整短链绑定后，短链 URL 不变，下一次访问立即生效。

## API Key 购买或使用引导入口

管理员可以在 `/admin/public-actions` 创建多个购买或申请入口，并启用其中一个作为当前公开入口。列表支持按名称、按钮文本和 URL host 搜索。

每个入口包含：

- 名称：后台识别用，不会下发前台。
- 按钮文本：前台纯文字按钮，例如 `购买 API Key`、`申请 API Key`。
- URL：外部供应商、充值页面或帮助文档地址。
- 启用状态。
- 当前公开状态：同一时间最多一个入口会作为公开入口。
- 后台备注：只在后台显示，不会下发前台。

启用某个入口为当前公开项时，系统会自动取消其它入口的当前公开状态。停用或删除当前公开入口后，前台会回到只显示 **点我配置**，直到管理员启用另一个入口。

保存 URL 时会复用公开 URL 安全校验：只允许 http/https，不允许 userinfo、危险协议、localhost、私网 IP、链路本地地址或保留地址。公共接口 `/api/public-runtime-config` 只返回：

```json
{
    "apiKeyPurchaseCta": {
        "label": "购买 API Key",
        "url": "https://supplier.example.com/buy"
    }
}
```

未配置、停用或配置非法时返回 `apiKeyPurchaseCta: null`。接口不会返回后台名称、备注、管理员信息、审计记录或任何 secret。所有新增、修改、启用、停用和删除操作都会写入审计日志，审计摘要只记录名称、按钮文本、URL host 和启停状态。

## 桌面端怎么读取展示内容

在 **Settings -> 桌面端设置** 里配置展示内容读取方式：

- **当前站点**：读取当前站点的 `/api/promo/placements`
- **自定义域名**：填写域名，系统自动拼成读取接口
- **完整接口**：直接填完整读取地址
- **关闭**：不请求展示内容接口

桌面端请求失败、离线或超时后，会直接隐藏展示内容，不会影响生成、编辑和历史。

如果后台展示组配置了指定域名约束，桌面端按它请求的远程展示服务域名匹配。例如完整接口配置为 `https://content.example.com/api/promo/placements` 时，服务端看到的域名通常是 `content.example.com`。

桌面端也会用同一远程服务来源读取 `/api/public-runtime-config`。读取成功且后台有当前公开购买入口时，缺配置提示会显示购买按钮；读取失败时安全降级为不显示购买按钮。

## 当前页面上的展示位

- 生成区头部：在编辑卡片标题右侧
- 页面顶部：在主页面标题下方
- 历史面板上方：在历史面板标题前

## 常见问题

### 为什么我只看见一张图？

先检查：

- 展示位是否启用
- 展示组是否启用且在有效时间窗内
- 素材是否至少有 2 张
- 素材是否启用且在有效时间窗内
- 素材的 `sortOrder` 和 `weight` 是否符合预期

### 为什么分享展示内容没出来？

先检查：

- 分享链接是否带了正确的 `promoProfileId`
- 后台分享展示组是否启用且未过期
- 当前访问域名是否命中分享展示组的域名约束
- 分享展示组是否绑定了目标展示位
- 展示素材是否有效
- 目标展示位是否启用

### 为什么一个展示位有多个展示组？

这是允许的。公共读取会选中当前有效且最近更新的那一组。
如果只是想做轮播，应该把多张图放进同一个展示组，而不是拆成多个展示组。
