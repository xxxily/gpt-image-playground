## 问题与解决

| 问题 | 解决办法 | 剩余风险 |
| ---- | -------- | -------- |
| 工作区包含其他用户/代理的未提交文档与研究文件 | 功能提交和发布提交均使用精确文件列表暂存，发布/部署使用 release commit 或 tag 的独立 worktree | 无关改动继续留在本地，后续操作仍不得误提交 |
| `npm audit` 前两次遇到 registry TLS 失败 | 保留失败证据并重试；第三次成功完成生产依赖审计 | 外部 registry 网络仍可能在 Action 或后续部署时波动 |
| Rust advisory DB 在线更新失败 | 使用本地 stale advisory DB 完成离线扫描 | `quick-xml 0.39.2` 仍命中 `RUSTSEC-2026-0194`、`RUSTSEC-2026-0195`，兼容修复受 Tauri 间接依赖与 Rust MSRV 约束 |
| 浏览器并行读取同一 Playwright 会话导致 CLI 会话退出 | 重新创建隔离会话并串行完成未来 recipe 深链检查 | 属于测试工具会话竞争，不是产品运行时错误 |

## 明确跳过与后续建议

- 当前会话没有可调用的内置图片生成能力，因此没有用色块或未经核验的素材冒充 24 个真实 AI 案例。
- 未执行 5 名非专业用户的 30/60 秒可用性测试，缺少真实受试者条件。
- 未安装 macOS、Windows、Linux 桌面包或 Android APK；Action 构建成功不能替代安装级真机验收。
- 外部 HTTPS 媒体仍需增加 DNS/重定向复检、MIME、体积和解码探测；多实例部署应使用共享卷或对象存储。
