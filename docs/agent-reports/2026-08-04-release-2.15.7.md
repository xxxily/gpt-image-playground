## 问题与解决

| 问题 | 解决办法 | 剩余风险 |
| ---- | -------- | -------- |
| 工作区包含其他用户/代理的未提交媒体、研究和部署文件 | 只暂存本任务的需求文档、报告、版本文件和 changelog；使用干净 detached worktree 做发布校验与部署 | 其他未提交改动仍留在本地，不属于本版本；后续提交时需继续避免混入 |
| “小版本”语义存在 patch/minor 歧义 | 按当前 `2.15.6` 基线和文档/审计性质采用补丁版本 `2.15.7`，并在 tag 前公开说明该假设 | `v2.15.7` 已按用户要求完成发布，无剩余执行歧义 |
| 文档显示专题能力仍有明确实现缺口 | 在需求中区分“文档完成”和“产品闭环完成”，不虚报真实媒体、漏斗或真机验收 | 专题整体仍为 `Partial`，后续必须完成第 29 章 P0/P1 门槛 |
| Action 有非阻塞告警 | 保留现有 release 产出，不把 warning 误报为失败；记录 checkout post-cleanup gitlink、GitHub Actions Node 20 deprecation 和未配置 Apple 签名材料 | macOS DMG 未签名/未公证；后续应升级 action runtime，并单独清理历史 gitlink warning |
