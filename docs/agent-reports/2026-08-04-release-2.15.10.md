## 问题与解决

| 问题 | 解决办法 | 剩余风险 |
| ---- | -------- | -------- |
| 搜索框看似即时，实际需要 Enter 才更新 | 本地结果即时过滤，300ms 防抖同步 URL，Enter 立即同步；移动端始终显示匹配数量 | 浏览器历史极端时序依赖 Next Router 最终收敛 |
| 搜索后快速排序、进入专题或重置会和延迟 URL 写入竞争 | 所有组合筛选使用当前草稿；专题页停止目录同步；重置取消计时器并同步清空草稿和 URL | 已完成 390×844 真实浏览器时序复验 |
| `rkyv 0.7.46` 间接漏洞来自日志插件 | 升级 `tauri-plugin-log 2.8.0 -> 2.9.0`，移除 `byte-unit -> rust_decimal -> rkyv` | `quick-xml` 仍来自 Tauri/Wayland 链 |
| 真实案例图片缺少可调用生成工具 | 按 `imagegen` 规范未静默调用需要 `OPENAI_API_KEY` 的 CLI，也未以占位冒充真实素材 | 需要内置生成工具恢复或用户明确授权 CLI/API 路径 |
| 多实例分析缺少集中存储契约 | 保留 owner/admin 受控、脱敏、有界 NDJSON 导出作为迁移面 | 规模运营前需接入明确的数据平台和幂等投递方案 |
| 部署后后台入口返回 500 | 定位为 `.env.production` 缺少认证键且部署覆盖远端共享环境；从部署前权限受控备份恢复 `BETTER_AUTH_SECRET` / `ADMIN_BOOTSTRAP_SECRET`，后台恢复 307 登录跳转 | 已补部署脚本远端 secret 继承、`--check-env` 和后台边界检查；需通过下一补丁发布固化 |
| 静态专题深链刷新出现 React #418 | 静态导出服务端只能渲染目录默认态，浏览器首轮却直接读取 query 渲染详情；改为挂载后再消费 `topic/case/q/filter` 参数 | 本地 production 浏览器已 0 error；修复不在已发布 tag 中，计划随 `v2.15.11` 发布 |
