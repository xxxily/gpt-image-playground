## 问题与解决

| 问题                                        | 解决办法                                                                                  | 剩余风险                                                                         |
| ------------------------------------------- | ----------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------- |
| MIME 通配为唯一值时无法先取消再选择具体类型 | 选择具体 MIME 自动移除 `image/*`；选择通配自动清空具体类型；始终至少保留一类              | 无已知交互风险                                                                   |
| 用户占位符元数据与 prompt 可能不一致        | 配方级 helper 同步添加/清理双语 `{{user_instruction}}`；关闭补充要求也清理 token          | 运营人员直接用高级 JSON 时仍需通过同一 schema 校验                               |
| URL 语法安全不能阻止 DNS/重定向 SSRF        | 发布时逐跳解析全部地址、拒绝任一非公网地址，并用 Node HTTPS `lookup` 固定连接到已校验地址 | 使用带 `signature`/token 查询参数的外部对象存储 URL 会被拒绝，应改用托管媒体上传 |
| 单请求超时无法限制慢 DNS 与多跳累计耗时     | 使用同一 deadline 覆盖 DNS、所有重定向、下载和 Sharp 元数据读取                           | CPU 极端繁忙时定时器与 Sharp 中止不是硬实时保证，但响应体和像素已设上限          |
